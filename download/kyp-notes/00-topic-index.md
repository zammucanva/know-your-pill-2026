# KYP Content Index
## New Oxford Textbook of Psychiatry, 2nd Edition (2009) — 8 uploaded parts

This is the proposed topic list for KYP note generation. Each entry becomes ONE
Markdown note (`<slug>.md`). Notes will be **original rewrites** — concepts
paraphrased from scratch, no copied text, tables, or criteria checklists from the
source book. Validated/licensed scales will be named and flagged, not reproduced.

**Priority tags**
- P1 = core clinical disorder note (the heart of KYP)
- P2 = strongly supporting clinical topic
- P3 = optional / reference / context

## Notes on granularity decisions (confirm or change)

1. **One note per disorder** (user direction, Sep 2026): the three planned
   schizophrenia notes were merged into a single `schizophrenia` note (~4,000
   words, all 16 sections) — one URL per disorder is the friendliest reading
   experience for students, clinicians and residents. Depression and bipolar
   likewise stay single notes.
2. **Merged chapters** where the book splits one disorder across many short
   chapters (alcohol, suicide, personality disorders).
3. **India context**: every note carries the mandated India subsections
   (epidemiology, practice, costs, counselling) regardless of source — these come
   from general Indian practice knowledge (NIMHANS/IPS practice norms, NMHS 2015-16
   survey, national programmes), not from this UK-authored textbook.
4. **Missing parts 6–7**: if uploaded, add Group S (somatoform/CFS/BDD/factitious,
   ~10 notes) and Group T (drug classes: antidepressants, antipsychotics, lithium,
   anxiolytics, ECT/TMS etc., ~12 notes) — both extremely KYP-relevant.
5. Slugs are lowercase-kebab; final filename = `<slug>.md`.
